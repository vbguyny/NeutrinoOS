Getting started

  1. Download the SDK archive (neutrinoos-sdk-*.tar.gz) and install the templates: 
    dotnet new install ./neutrinoos-sdk/templates
  2. Create a project and build it: 
    dotnet new neutrino-console -n MyApp
cd MyApp
dotnet build -c Release   # -> MyApp.npkg
  3. Serve it and install it on a device: 
    scripts\start-repo-server.ps1
neutrinoos> npkg repo add local http://10.0.2.2:8080
neutrinoos> npkg install MyApp
